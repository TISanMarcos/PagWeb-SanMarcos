# Fuentes oficiales — San Marcos Brand Book

Coloca aquí los archivos web de las fuentes licenciadas:

| Familia   | Uso     | Pesos sugeridos                          |
|-----------|---------|------------------------------------------|
| Collier   | Títulos | Regular, Bold, Black (+ Italic si aplica) |
| Amsi Pro  | Cuerpo  | Regular, Semibold, Bold                  |

Formato recomendado: `.woff2`

Fuentes disponibles en [Adobe Fonts (Collier)](https://fonts.adobe.com/fonts/collier) y [MyFonts (Amsi Pro)](https://www.myfonts.com/collections/amsi-pro-font-stawix).

Mientras no estén los archivos, el sitio usa **Fraunces** y **Nunito Sans** como sustitutos cercanos.
